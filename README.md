# Santa Cruz Odontologia

Site institucional responsivo em uma página, feito com HTML, CSS e JavaScript. Abra `index.html` no navegador ou publique a pasta inteira em uma hospedagem de sites estáticos.

## Conteúdo

- Fotos, símbolo, endereço, telefones e avaliações fornecidos para este projeto.
- `fachada-alta-resolucao.png`, `recepcao-alta-resolucao.png` e `consultorio-alta-resolucao.png` são restaurações em maior resolução das fotos fornecidas; os arquivos originais permanecem em `assets/`. A foto com pessoas permanece original.
- Botões de agendamento abrem o WhatsApp da clínica com uma mensagem inicial.
- Links de localização abrem o perfil da clínica no Google Maps.
- Mini mapa no rodapé com marcador da localização e link direto para o Google Maps informado.

Antes de publicar, confirme com a clínica a autorização de uso das fotos e a atualização dos dados de contato e avaliações.
